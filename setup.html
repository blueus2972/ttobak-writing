학급 연결 안내

연습장과 이미지 저장은 바로 사용할 수 있습니다. 학급 관리와 학생 제출은 아래 연결을 한 번 마치면 사용할 수 있습니다.

  1. Supabase에서 새 프로젝트를 만듭니다.
  2. SQL Editor에서 GitHub의 supabase/schema.sql 내용을 실행합니다. 기존 프로젝트에 이미 적용했다면 다시 실행하지 마세요.
  3. 교사로 사용할 이메일을 SQL Editor에서 등록합니다.
    insert into ttobak_private.teacher_allowlist(email)
values(lower('교사이메일@example.com')) on conflict do nothing;
  4. Authentication 설정에서 이메일/비밀번호 가입과 이메일 인증을 켜고, Anonymous Sign-Ins(익명 로그인)를 켭니다. 학생 개인 입장 코드 확인 전에 이 익명 세션을 만듭니다.
  5. Authentication → URL Configuration에서 Site URL을 Vercel 사이트 주소로 설정하고 해당 주소를 Redirect URLs에도 추가합니다.
  6. Vercel → Settings → Environment Variables에 프로젝트 URL과 공개 키를 넣습니다.
    SUPABASE_URL=https://프로젝트ID.supabase.co
SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
    이전 anon 공개 키는 SUPABASE_ANON_KEY로 넣을 수 있습니다. service_role / sb_secret_ 관리자 키는 사용하지 마세요.
  7. Vercel에서 새 배포를 실행합니다. 교사 화면에서 계정을 만들고 이메일 인증 후 로그인합니다.
  8. 학급을 만들고 학생 번호·이름을 등록합니다. 학급 코드와 학생별 개인 입장 코드를 해당 학생에게 전달합니다.

제출물 접근 범위

비공개 Storage 버킷과 RLS를 사용합니다. 교사는 자신이 만든 학급의 제출물만, 학생은 자신의 제출물만 볼 수 있습니다. 이미지 링크는 5분 뒤 만료됩니다. 입장 코드 재발급·중지 시 기존 학생 세션의 접근 권한도 회수됩니다.

학생 이름·입장 코드·이미지를 GitHub에 올리지 마세요. 학생 코드는 교사 화면에서 발급 직후 한 번 표시됩니다. 연결 완료 후 별도 테스트 학급으로 제출과 교차 접근 차단을 확인하고 실제 학생에게 안내해 주세요.
