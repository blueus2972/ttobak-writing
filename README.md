# 또박또박 · 손글씨 연습장

문구, 격자, 서체, 색상과 종이 방향을 선택하는 독립적인 손글씨 연습장 도구입니다.

## 기능
- 문장 반복, 첫 줄 견본, 흐려지는 따라쓰기, 줄 번호
- 십자, 점선, 미자, 네모, 4선, 밑줄, 빈 종이
- 한글/일본어/중국어/영문 서체와 글자 크기
- 6가지 종이 테마, 테두리, 장식, 내 이미지
- A4 세로/가로, 자동 여러 페이지, 인쇄/PDF 저장
- 마우스/터치/펜 쓰기, 지우개, 되돌리기
- 브라우저에 설정 저장

## Vercel 배포
1. Vercel에서 Add New → Project를 선택합니다.
2. 이 GitHub 저장소를 Import합니다.
3. Framework Preset: Other, Root Directory: ./
4. Build Command는 비워 두고 Output Directory: . (또는 기본값)을 사용합니다.
5. Deploy를 누릅니다. 환경 변수와 별도 서버가 필요하지 않습니다.

## 로컬 실행
Node.js 설치 후 `npm run dev`로 실행하고 http://localhost:5173 을 엽니다.

## 인쇄
인쇄 대상을 ‘PDF로 저장’으로 선택하면 PDF를 만들 수 있습니다. A4, 배율 100%, 여백 없음, 머리글/바닥글 끄기를 권장합니다. 종이 색이 필요하면 배경 그래픽을 켜세요. 펜 입력은 인쇄에 포함됩니다. 설정을 변경하면 기존 펜 입력은 지워집니다.

설정만 로컬 저장되며 이미지와 펜 입력은 새로고침 후 유지되지 않습니다. 서체는 Google Fonts에서 제공되며 인터넷 연결이 없으면 기기 기본 서체를 사용합니다. 자동 맞춤법 교정은 포함하지 않습니다.

참고 사이트의 코드를 복제하지 않고 기능을 참고해 별도로 구현했습니다.
